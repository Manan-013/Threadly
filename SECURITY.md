# Security Policy

## Supported Versions

We release security updates and bug fixes for the current major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Threadly team takes the security of our extension and backend services seriously. If you discover a potential vulnerability, please report it responsibly:

1. **Do not create a public GitHub Issue.**
2. Email your findings directly to the maintainer or use GitHub's private vulnerability reporting feature:
   - Navigate to the **Security** tab of the repository.
   - Click **Report a vulnerability**.
3. Include detailed reproduction steps, proof of concept, and impact assessment.

We will acknowledge receipt within 48 hours and work with you to triage and release a coordinated fix.
